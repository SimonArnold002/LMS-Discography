PLUGIN_DISCOGRAPHY_SHOW_STREAM_EXTRAS_DESC
	EN	Show a section of albums your streaming services carry for this artist that MusicBrainz did not list - so nothing playable is missed. These albums ARE playable, so "Hide releases you can't play" does not apply to them; they are missing from MusicBrainz, not missing a source. UNVERIFIED: because MusicBrainz does not list these releases, it cannot confirm who made them. Where a streaming service files several acts of the same name under one artist (Qobuz does this for "Madness"), the other acts' records will appear here too. Releases in the main discography are unaffected. Off by default.

PLUGIN_DISCOGRAPHY_MB_BASE_URL
	EN	MusicBrainz server

PLUGIN_DISCOGRAPHY_MB_BASE_URL_DESC
	EN	The MusicBrainz web-service base URL. Leave this blank to auto-detect a musicbrainz-docker mirror running on this same machine (port 5000), falling back to the public API (https://musicbrainz.org/ws/2/) if none is found. Or point it at your own local mirror (e.g. http://your-server:5000/ws/2/) for fast, un-throttled lookups; a mirror speaks the identical API and the 1 req/s courtesy delay is dropped automatically. Include the http:// or https:// scheme (a bare host is assumed to be http://). Cover art still comes from the public Cover Art Archive.
