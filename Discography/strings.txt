PLUGIN_DISCOGRAPHY_MB_BASE_URL
	EN	MusicBrainz server

PLUGIN_DISCOGRAPHY_MB_BASE_URL_DESC
	EN	The MusicBrainz web-service base URL. Leave this blank to auto-detect a musicbrainz-docker mirror running on this same machine (port 5000), falling back to the public API (https://musicbrainz.org/ws/2/) if none is found. Or point it at your own local mirror (e.g. http://your-server:5000/ws/2/) for fast, un-throttled lookups; a mirror speaks the identical API and the 1 req/s courtesy delay is dropped automatically. Include the http:// or https:// scheme (a bare host is assumed to be http://). Cover art still comes from the public Cover Art Archive.
